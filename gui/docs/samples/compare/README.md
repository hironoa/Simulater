# 波形比較の動作確認用データ

波形比較の機能を手で確かめるためのデータです。変更前（A）と変更後（B）の CSV と、信号定義の YAML の 3 つを使います。

| ファイル | 中身 |
| --- | --- |
| `engine_test_A.csv` | 変更前（A）。1000 ステップ（周期 5 ms で 0〜5000 ms） |
| `engine_test_B.csv` | 変更後（B）。800 ステップ（0〜4000 ms） |
| `engine_test_config.yaml` | 状態名、単位、LSB、無効区間（`PIG` が 0 の間を「IG OFF」）の定義 |

## 開きかた

1. `engine_test_B.csv` と `engine_test_config.yaml` を一緒にドロップする（または「開く」で 2 つを選ぶ）。
2. 「開く ▼」→「比較する CSV（A）を開く」で `engine_test_A.csv` を選ぶ。
3. 周期は初期値の 5 ms のまま使う。

## 見えるはずの差分

時刻は ms です。CSV の 1 行目のデータはステップ 1 として読み込まれるので、時刻は 5 ms 単位で次のようになります。

| 信号 | 種類 | 区間 | 確かめること |
| --- | --- | --- | --- |
| `CurrentGear` | タイミングのずれ | 905〜955、1605〜1655 | 寸法線と「50 ms 遅れ」 |
| `JudgeFlag` | タイミングのずれ | 1005〜1055、2005〜2055 | 寸法線と「50 ms 遅れ」 |
| `EngineSpeed` | 値の違い | 1110〜1405 | 2 本の線の間の赤い塗りと、下の Δ の波形 |
| `DriveMode` | 値の違い | 2455〜2485 | B だけにある短い「Eco」が、タイミングのずれではなく値の違いになる |
| `CurrentGear` | 値の違い | 2905〜3205、3505〜4000 | A は 4th、B は 5th。IG OFF の区間で 2 つに分かれる |

サイドバー下の「比較の結果」は「値の違い 4 区間 / 1120 ms」「タイミングのずれ 4 件（すべて 50 ms 遅れ）」になります。

## 差分にならないはずのもの

| 信号・区間 | 理由 |
| --- | --- |
| `EngineSpeed` の 3300〜3400 | A と B で値は違うが、IG OFF（3205〜3505）の中なので比べない |
| `WaterTemp` | A には空欄の行があるが、直前の値で埋めると B と同じになる |
| `PIG` | A と B で同じ |
| 4000 ms より後ろ | B に記録がない。時間軸は A の終わり（5000 ms）まで延び、A だけが描かれ、B は「値なし」 |

## 片方にしかない信号

- `DiagCounter` は B だけにある（「B のみ」）。
- `OldSignal` は A だけにある（「A のみ」）。

## 作り直すとき

このデータは、周期 5 ms で sin 波と決まった切り替わり時刻から作っています。値を変えたいときは、上の表の区間と「比較の結果」の値も合わせて直してください。
