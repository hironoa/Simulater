信号設定 UI モック（LSB / オフセット対応）

既存のサイドバー・モーダルの Tailwind クラスを流用しています。セクション見出しのクリックで開閉、案A の物理値変換は入力に追従します。

案A：信号ごとの設定パネル（セクション折りたたみ）

歯車で開くパネルを「表示 / 物理値変換 / Y軸スケール / Y軸省略」の4セクションに分割。閉じたセクションは見出しの右に現在値の要約を出す。開閉状態は全信号で共有して記憶する想定。

案B：一覧編集ダイアログ（全設定項目）
