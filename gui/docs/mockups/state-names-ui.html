状態名設定 UI モック

既存のサイドバー・一覧編集ダイアログの Tailwind クラスを流用しています。入力は波形エリアのプレビューと一覧のセルに追従します（保存はしません）。

閉じたときの要約（比較）

状態名は長いことが多く、サイドバー幅（要約欄 約170px）には並べられない。名前は出さず、色チップ＋件数で「何件あるか・どの色で描かれるか」だけを示す案を推奨。チップにマウスを乗せると「値: 状態名」をツールチップで表示。

案A：信号設定パネルに「状態名」セクションを追加

「物理値変換」と「Y軸 スケール設定」の間に配置。歯車で別の信号に切り替えられます。行の確定は Enter / フォーカスが外れたとき、Esc で元に戻す想定（モックでは入力のたびに反映）。

    案B：一覧編集ダイアログに「状態名」列を追加

    「物理値変換」の列セット（除外値の右）に追加。セルには要約（色チップ＋件数）だけを出し、クリックで案A と同じ編集表をポップオーバーで開く。他の信号からのコピーで、期待値信号などに同じ定義を流用できる。変更は「適用」まで反映しない（変更セルは黄色）。
