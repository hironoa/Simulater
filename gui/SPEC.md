# 波形比較（A と B の CSV の重ね表示）

## 目的
プログラムを変更したとき、変更する前に取った CSV と変更した後に取った CSV を見比べて、どこで、どう変わったかを確かめたい。
今のビューアは CSV を 1 つしか開けないので、2 つのファイルを別々に開いて目で見比べるしかない。
2 つ目の CSV を重ねて表示し、値の違いとタイミングのずれを自動で見つけて、波形の上に示す機能を加える。

画面のイメージは `docs/mockups/waveform-compare-ui.html` にある（ブラウザで開くと操作できる）。

## 用語
- **A**：比べる元の CSV。比較を始めるときに追加で開く。
- **B**：比べる CSV。今まで開いていた CSV がそのまま B になる。
- **Δ**：B − A。
- **値の違い**：同じ時刻で A と B の値が違う区間。
- **タイミングのずれ**：状態信号で、A と B の切れ目（値が変わる時刻）が同じ変わり方のまま前後にずれているもの。「50 ms 遅れ」のように、B が A より遅いか早いかで表す。

## 画面仕様

### 1. 比較の開始と終了
- 「開く」メニューに「比較する CSV（A）を開く」を加える。開くと比較が ON になる。
- B を開いていて A がないときは、ファイル名の欄に「＋ A を開く」を出す。クリックで選ぶか、そこへのドロップで A を開く。
- B を開いているときに CSV をドラッグすると、画面を左右 2 つの受け口に分ける（左「B として開く（今までどおり）」、右「A（比較元）として開く」）。波形 CSV を 2 つまとめてドロップしたときは、更新日時の古い方を A、新しい方を B にする。
- A と B のファイル名の間の「⇆」で A と B を入れ替える。信号の設定、カーソル、表示範囲（時刻）は保ち、自動再読み込みの対象（ファイルの場所）も一緒に入れ替える。
- ツールバーのファイル名の欄は A → B の順に `A engine_test_old.csv ✕ | B engine_test.csv` と並べる。✕ で比較を終える（A を閉じる）。
- ツールバーの「比較」ボタンで、A を開いたまま重ね表示だけを切り替えられる。ON のときはボタンを青くする。OFF のときは今と同じ画面にする。
- A と B は時刻（ステップ × タスク周期）で揃える。片方にしかない時刻は、ない側を「値なし」として扱う。
- 片方にしかない信号は、ある側だけを描く。サイドバーと信号名の下に「B のみ」（または「A のみ」）と出す。

### 2. 波形の描き方
- **アナログ信号**：B は今と同じ実線。A は同じ色の薄い破線で重ねる。
  - 値の違う区間は、2 本の線の間を薄い赤で塗る。
  - 値の違いがある信号は、レーンの下に Δ の小さな波形（高さ 20 px ほど、表示範囲の最大の絶対値で振れ幅を合わせる）を出す。行名の「Δ」は、状態信号の「A」「B」と同じく縦軸の左に置き、ゼロの線に重ねない。
- **状態信号（状態名を持つ信号）**：比較が ON のときは、A と B を同じ高さの上下 2 段で描く（上が A、下が B）。
  - 2 段とも、今の状態表示と同じ色の帯、状態名、段差の線で描く。A の段差の線は少し薄くする。左端に「A」「B」と書く。
  - A と B が食い違う区間は、2 段をまとめて淡い赤の細い枠と薄い斜線で囲む。状態の切れ目（段差の線や帯の境目）が埋もれない濃さにする。
- **タイミングのずれ**：A と B の切れ目から補助線を下ろし、レーンの下に両矢印の寸法線を引いて、中央に「50 ms 遅れ」「30 ms 早い」と書く。
- **数値の常時表示はしない**。アナログの差は、マウスの位置（Hov の縦線）で A と B が違い、Δ の小波形の行があるときだけ、波形上の点に小さな丸を付け、横に `Δ +151.98 rpm` の札を出す。札は波形と共通の座標計算を使って点に沿って上下し、ズームで振れ幅が変わっても点に一致する。札本体は行の上下端で位置を寄せ、下の時間軸の目盛りや次のレーンに重ならないよう配置する。Δ = 0 の位置では札を出さない。

### 3. 差分の検出
- 生の値（物理値に変換する前の値）で比べる。許容誤差は 0。
- 無効区間（`inactive`）は、A と B のどちらかが無効の時刻を比べる対象から外す。
- タイミングのずれは状態信号だけを対象にする。A と B の切れ目のうち、変わり方（変わる前の値 → 変わった後の値）が同じで、時刻の差が許容幅（初期値 500 ms）以内のものを組にする。組にならなかった切れ目の区間は「値の違い」として扱う。
- 1 つの差分は「信号、種類（値の違い / タイミングのずれ）、開始時刻、終了時刻」を持つ。タイミングのずれは A の切れ目と B の切れ目の時刻も持つ。

### 4. 差分の移動と絞り込み（ツールバー）
- ◀ ▶ で前後の差分へ移動する。移動すると、その差分が中央に来るようにズームし、点線の枠で示す。間に「差分 3 / 6」と位置を出す。
- 「全体」で全体表示に戻す。
- 絞り込み：「差分: すべて / 値の違いだけ」。
- 「差分のある信号だけ」にチェックすると、差分のない信号を隠す。
- 下のズームバー（データズーム）の水色の部分（上端の移動用つまみより下）に、差分のある区間を始まりから終わりまでの幅の帯（値の違い = 赤、タイミングのずれ = 琥珀色）で出す。帯はズームバーの下に描き、つまみや選択範囲を隠さない。ごく短い区間も見えるよう、帯の幅は最小 2px とする。

### 5. サイドバー
- 信号ごとに印を付ける：`≠n`（値の違いの数）、`⏱n`（タイミングのずれの数）、`=`（差分なし）、`B のみ`。
- 下に「比較の結果」として、値の違いの区間数と合計時間、タイミングのずれの数、判定の条件（生値、許容誤差、無効区間の扱い）を出す。

### 6. マーカーとラベル
- カーソル位置の値は、A と B が同じときは今と同じく値だけを出す。
- 違うときは「A …」（赤）と「B …」を出す。状態信号は A の段に「A …」、B の段に「B …」を出す。アナログ信号はそれぞれの線上の点の横にラベルを出し、近いラベルは既存の重なり回避で上下にずらす。A の点は点線の丸で示す。画面と画像コピーで同じ配置にする。

### 7. 計測表
- 比較中は信号ごとに A / B の列を並べ、アナログ信号は Δ 列も足す。
- 見出しは 2 段にし、1 段目の信号名（と単位）はその信号の A / B / Δ の列にまたがる 1 つのセルにまとめる。2 段目に A、B、Δ を書く。縦横入替の表示では、信号名のセルを A / B / Δ の行にまたがってまとめ、右隣の列に A、B、Δ を書く。
- A と B が違うセルは赤の太字にする。

### 8. 保存と自動再読み込み
- `.wcp` に A の CSV も入れて保存し、開いたときに比較の状態を戻す。A がない `.wcp` は今までどおり開ける。
- 自動再読み込みは B だけを対象にする。
- 「前回を A に残す」を ON にすると、読み直すたびに前回読んだ内容と比べ、新しいテストかどうかを判断する。WinAMS はテスト中に同じ CSV を書き足し、流し直すときは中身を空にして先頭から書き直すため。
  - 前回の内容（書きかけかもしれない最後の行を除く）が新しい内容の先頭にそのまま残り、行数が減っていなければ「続き」とし、B だけを更新する。
  - そうでなければ「新しいテスト」とし、前回読んだ B を A にして、新しい内容を B にする。
  - データの行がまだないとき（空にした直後や見出しだけのとき）は何もせず、次の変化を待つ。この扱いは設定が OFF のときも同じ。
- 「B を A にする」ボタンで、今の B を次の比較の A にできるようにする（変更を繰り返すときに使う）。

## 実装計画
Codex に段階ごとに実装を任せ、段階ごとに型チェック、ビルド、ブラウザでの確認を行ってからコミットする。

### 1. 差分検出と A の読み込み
- `src/utils/compare.ts` を新しく作り、A と B の `ChartData`、状態名の対応（`modeMapping`）、無効区間の結果を受け取って差分の一覧を返す関数を置く。描画や React に依存しない純粋な関数にする。
- `src/store/useWaveformStore.ts` に、A の `ChartData`、ファイル名、元の CSV 文字列、比較の ON / OFF、差分の一覧、絞り込みの状態、注目中の差分を持たせる。A を開く処理と閉じる処理、「B を A にする」処理を加える。A を開くときは今の CSV 読み込み処理（`parseWaveformCSV`）と同じ解析を使い、B の設定（信号の設定、グループ、カーソルなど）を変えない。

### 2. 波形への描画
- `src/utils/chartOptionsBuilder.ts` と `src/components/Chart.tsx` で、比較が ON のときに A の破線、値の違いの塗り、Δ の波形、状態信号の上下 2 段、斜線の枠、寸法線を描く。
- Y 軸の分断（`breaks`）がある信号でも、データを書き換えずに ECharts の機能で描く（AGENTS.md の決まり）。
- 比較が OFF のときに今の描画が変わらないようにする。

### 3. ツールバー、サイドバー、計測表、ラベル
- `src/components/Toolbar.tsx` に比較の切り替え、◀ ▶、全体、絞り込み、「差分のある信号だけ」を加える。
- `src/components/Sidebar/` に信号ごとの印と比較の結果を出す。
- `src/components/MeasureTable.tsx` に A / B / Δ の列を加える。
- カーソルのラベルと Hov の Δ の札を出す。

### 4. 保存、自動再読み込み、文書
- `.wcp` の保存と読み込みに A を加える（`getConfigYAML`、`parseMappingData` と `.wcp` の zip 処理）。
- `src/hooks/useWaveformAutoReload.ts` で B だけを読み直し、差分を計算し直す。
- `README.md` に比較機能の使い方を書き、画面写真を加える。`npm run build` で `winams_csv_viewer.html` を作り直す。

## 検証内容
1. 【比較 OFF の回帰】A を開かない状態と比較 OFF の状態で、今の表示（状態表示、無効区間、マーカー、ラベル、計測表、画像書き出し）が変わらないことを確かめる。
2. 【値の違い】アナログ信号の一部区間だけ値を変えた A を用意し、赤い塗り、Δ の波形、Hov の Δ の札、計測表の Δ 列が正しい区間と値で出ることを確かめる。
3. 【タイミングのずれ】状態信号の切り替わりを 50 ms ずらした A を用意し、寸法線と「50 ms 遅れ」が出ること、早めた場合に「早い」と出ることを確かめる。
4. 【状態の値の違い】状態の値そのものが違う区間を作り、2 段まとめた斜線の枠が出て、状態の切れ目が読めることを確かめる。
5. 【無効区間】無効区間の中の違いが差分に数えられないことを確かめる。
6. 【長さや信号の違い】A と B で時間の長さや信号の組み合わせが違っても、エラーにならず、片方だけの信号に「A のみ」「B のみ」と出ることを確かめる。
7. 【移動と絞り込み】◀ ▶、全体、絞り込み、「差分のある信号だけ」が動くことを確かめる。
8. 【保存と自動再読み込み】A を含めて `.wcp` に保存し、開き直して比較の状態が戻ること、A のない古い `.wcp` も開けること、自動再読み込みで B だけが読み直されることを確かめる。
9. 【ビルド】`npm run lint` と `npm run build` が通り、`winams_csv_viewer.html` で同じ動きになることを確かめる。
